# Сайт тату-студии «Грамма»

Одностраничный лендинг студии «Грамма» (Владимир) — gramma.tattoo.

## Структура

- `index.html` — разметка страницы;
- `src/style.css` — стили, написаны мобайл-ферст: базовые для телефона, шире через `min-width`;
- `src/main.js` — скрипт: ленты работ на первом экране, ленты в карточках мастеров, просмотр работы;
- `src/fonts/` — шрифты SN Pro (текст, 400 и 600) и Unbounded (заголовки, 700 и 900) в woff2, подключены в начале `style.css`; лицензии SIL OFL рядом;
- `public/img/` — фото работ, студии, мастеров и логотипы, копируются в сборку как есть:
  - `naya-NN.webp` / `shuga-NN.webp` — работы мастеров (до 1400 px), `-s` — превью (до 640 px);
  - `room-NN.webp` — интерьер студии, `master-*.webp` — портреты мастеров;
- `vite.config.js` — настройки сборки;
- `.github/workflows/deploy.yml` — сборка и публикация на GitHub Pages.

## Сборка и публикация

Каждый пуш в `main` запускает GitHub Actions: Vite собирает сайт в `dist/` (стили и скрипт минифицируются, у файлов в имени хеш, из HTML убираются комментарии и лишние пробелы) и выкладывает его на GitHub Pages. Ход сборки виден на вкладке Actions.

## Работа на своём компьютере

Нужен Node.js 18 или новее.

```
npm install
npm run dev       # сайт с автообновлением на http://localhost:5173
npm run build     # сборка в dist/
npm run preview   # посмотреть собранную версию
```

## Как добавить работу

1. Сохраните фото в `public/img/` как `shuga-24.webp` и `shuga-24-s.webp` (или `naya-23…`).
2. В `src/main.js` в массив `ALT.shuga` (или `ALT.naya`) добавьте подпись в конец списка.
