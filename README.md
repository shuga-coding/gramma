# Сайт тату-студии «Грамма»

Одностраничный лендинг студии «Грамма» (Владимир) — gramma.tattoo.

## Структура

- `index.html` — вся страница: разметка, стили и скрипт в одном файле.
- `img/` — фото работ, студии, мастеров и логотипы.
  - `naya-NN.webp` / `shuga-NN.webp` — работы мастеров (до 1400 px), `-s` — превью (до 640 px).
  - `room-NN.webp` — интерьер студии, `master-*.webp` — портреты мастеров.

## Как добавить работу

1. Сохраните фото в `img/` как `shuga-24.webp` и `shuga-24-s.webp` (или `naya-23…`).
2. В `index.html` в массив `ALT.shuga` (или `ALT.naya`) добавьте подпись в конец списка.

## Локальный просмотр

Откройте `index.html` в браузере или запустите `python3 -m http.server` в папке и зайдите на http://localhost:8000.

## Публикация

Подойдёт GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
